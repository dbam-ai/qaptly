> **Notice**: The source code for this project is private and not open source.

[![GitHub issues](https://img.shields.io/github/issues/dbam-ai/qaptly)](https://github.com/dbam-ai/qaptly/issues)

An AI-powered tool to help SQA engineers create and maintain test cases efficiently.

---

## 🚀 Features

- **AI Test Case Generation**: Automatically generate test cases from requirements or user stories.
- **Smart Maintenance**: Update existing test cases when application behavior changes.
- **Template Library**: Leverage and customize a library of test case templates.
- **Collaboration**: Track and manage issues directly in this repository.

---

## 📦 Download & Installation

Please go to the [Releases page](https://github.com/dbam-ai/qaptly/releases) to download the latest installer (DMG for macOS, EXE for Windows, etc.), and follow platform-specific instructions:

1. Download the installer and run it.
2. Launch qaptly after installation.
3. Log in with your qaptly.dbam.ai account when prompted.

---

## 📖 Usage

1. **Login**: Authenticate with your qaptly.dbam.ai account.
2. **Create/Open Project**: Manage test cases for different products or modules.
3. **Generate Cases**: Input requirements or user stories to auto-generate test cases.
4. **Edit & Maintain**: Adjust or regenerate to keep cases aligned with changes.
5. **Export**: Export test suites in CSV or JSON formats.

# Qaptly

> **注意**: 本專案原始程式碼並非公開開源。
> **本公開倉庫僅供 Release（安裝套件）與 Issue 管理使用。**

[![GitHub releases](https://img.shields.io/github/v/release/dbam-ai/qaptly)](https://github.com/dbam-ai/qaptly/releases)
[![GitHub issues](https://img.shields.io/github/issues/dbam-ai/qaptly)](https://github.com/dbam-ai/qaptly/issues)

一款專為 SQA 工程師打造的 AI 工具，協助建立與維護測試案例。

---

## 🚀 功能

- **AI 測試案例產生**：根據需求或用例自動產生測試案例。
- **智慧化維護**：當應用行為改動時，自動更新既有案例。
- **範本庫**：使用並自訂多種測試案例模板。
- **協作管理**：在本倉庫提交 Issue，追蹤需求與問題。

---

## 📦 下載與安裝

請至 [Releases 頁面](https://github.com/dbam-ai/qaptly/releases) 下載最新版本的安裝檔（macOS DMG、Windows 安裝程式等），並依作業系統指引安裝：

1. 下載安裝檔並執行。
2. 安裝完成後，啟動 qaptly。
3. 首次使用時，請使用您在 qaptly.dbam.ai 申請的帳號登入。

---

## 📖 使用說明

1. **登入**：使用 qaptly.dbam.ai 帳戶驗證。
2. **建立／開啟專案**：管理不同產品或模組的測試案例。
3. **生成案例**：輸入需求或使用者故事，自動產生測試案例。
4. **編輯與維護**：調整或重新生成，保持案例與需求一致。
5. **匯出**：支援 CSV、JSON 格式輸出。
