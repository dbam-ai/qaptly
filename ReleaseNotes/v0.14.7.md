# Qaptly v0.14.7 Release Notes

**Release Date**: December 17, 2025

## What's New

### Visual Change Detection
Automatically detect and highlight visual differences in your mobile app screens during testing. This helps you quickly spot unexpected UI changes and ensure consistent user experience.

### Simplified Android Testing Setup
No need to manually install Android development tools anymore. Qaptly now automatically downloads and configures everything needed for Android testing - just connect your device and start testing.

### Improved Test Management
- Enhanced interface for managing connected devices and test pilots
- Better organization with a new tab-based layout
- Clearer visibility of available features based on your subscription plan

### Enhanced Mobile Test Designer
Track your testing activities with improved analytics and insights. Better understand how you're using the test designer and optimize your testing workflow.

## Improvements

- Redesigned settings interface with more compact layout
- Screenshots are now automatically organized by date in a dedicated folder
- More reliable error handling throughout the application
- Better device connection management

## System Updates

This release includes updated system components (qaptly_mac_cmd v0.29.2) with improved Android device communication and better support for various Android versions.

## Installation

Download the DMG file, open it, and drag Qaptly to your Applications folder. If you're upgrading from a previous version, simply replace the existing app.
