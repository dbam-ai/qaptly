# Release Notes - Qaptly v0.15.0

**Release Date**: 2025-12-31

## What's New

### Improved Mobile Device Control
- **Faster and More Reliable**: Mobile automation is now handled directly by Qaptly, providing quicker response times and better reliability
- **Better Error Messages**: Clearer error messages when device connection issues occur
- **Cross-Platform Ready**: Architecture improvements to support future Windows automation

### New User Onboarding Experience
- **Guided Setup**: New users are greeted with a helpful 6-step tour introducing Qaptly's main features
- **Easy Account Creation**: New signup flow with streamlined registration
- **Re-run Anytime**: Access the onboarding tour again from Settings if needed

### Enhanced Analysis Window
- **Session Memory**: Your analysis sessions are now saved and restored when you reopen the window
- **Better Image Preview**: New floating panel with zoom controls for detailed screenshot inspection
- **Smart Filtering**: Automatically group and collapse similar screenshots to focus on what matters
- **Change Detection Tuning**: Adjust the sensitivity of visual change detection in settings

### Scene Review Workflow
- **Review Before Commit**: New workflow to review scene changes before saving them
- **Real-time Updates**: See changes as they happen with live updates

## Improvements

- Localized Terms of Use and Privacy Policy links (English, Japanese, Traditional Chinese)
- Improved BDD test case viewer with better data format support
- Better device status display and refresh behavior
- Complete language support for all Pilot Control features
