# v0.14.5 - Property Condition Editor and Mobile Analysis Enhancements

**Release Date**: 2025-12-09

---

## What's New

### Property Condition Editor for Mobile Test Steps
- **NEW**: Advanced property-based verification for mobile UI elements
- Support for dot notation to access nested properties (e.g., `bounds.width`, `bounds.center.x`)
- Range operators for numeric comparisons (`>`, `<`, `>=`, `<=`, `==`, `!=`)
- Auto-population of property values from current UI element
- Support for reference elements without meaningful attributes
- Comprehensive internationalization support (EN, JA, ZH-TW)

### Screenshot Similarity Metrics for Mobile Analysis
- **Enhancement**: Multi-layer similarity detection for mobile screenshots
- Four similarity algorithms: Pixel Difference, SSIM (Structural Similarity Index), Perceptual Hash (pHash), and Rolling baseline tracking
- Intelligent duplicate detection with multiple comparison layers
- Better screenshot analysis and session quality

### Analysis Window Naming Consistency
- **Improvement**: Unified naming across the application
- Consistent terminology in UI and internationalization resources
- Better user experience with clearer navigation

### Macro Manager Internationalization
- **Enhancement**: Full internationalization support for Macro Manager
- Support for English, Japanese, Traditional Chinese, and Simplified Chinese
- Unified terminology across the application
