# v0.14.1 - Infrastructure & UX Improvements

**Release Date**: 2025-12-04

## What's New

### Subscription & Feature Management

**NEW**: Complete subscription-based feature control system

- Centralized subscription state management with real-time updates
- Feature availability checking based on your subscription plan
- Credit balance tracking and monitoring
- Test Case Selector Dialog for easy test case selection across platforms
- Integrated with Mobile Test Designer for seamless workflow

### Improved Error Handling

**IMPROVED**: More robust API error handling

- Better handling of common error scenarios
- Automatic logout when seat is revoked
- Clear error messages for version compatibility issues
- Automatic handling of insufficient credits
- Feature limit notifications

### Settings Window Redesign

**REDESIGNED**: Modern, intuitive settings interface

- **Immediate Save**: Language and preferences now save instantly - no more confusing Save/Cancel buttons
- **Smarter Path Settings**: Save/Cancel buttons only appear when you modify paths
- **Wider Input Fields**: Path inputs are now wider and responsive to window size
- **Cleaner Layout**: Modern sidebar navigation with better organization
- **Better UX**: Clear feedback when settings are saved

---

## Bug Fixes

- Fixed automatic logout when subscription seat is revoked
- Fixed confusing Settings UI with always-visible Save/Cancel buttons
- Improved Settings input field widths for better path visibility

## Installation

### First-time Installation
Download `Qaptly-0.14.1-arm64.dmg` from the releases page and install.

### Updating from v0.14.0
The app will automatically update to v0.14.1 when you restart it.

### Manual Update
Download `Qaptly-0.14.1-arm64-mac.zip`, extract, and replace your existing app.
