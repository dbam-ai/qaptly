# v0.13.4 - Environment Management & Real-time Updates

**Release Date**: 2025-11-19

## What's New

### Environment Management System
- Complete environment variable management with CRUD operations
- Dedicated environment editor dialog for managing test environments
- Horizontal scrollable environment selector for easy switching
- Persistent environment selection across sessions

### iOS Device Management
- Running Apps button for viewing currently active iOS applications
- Enhanced screenshot display and management
- Improved iOS device integration

### Real-time UI Updates
- Test round status updates automatically without page refresh
- Control buttons (Start/Stop/Resume) enable/disable instantly
- Progress statistics update in real-time during test execution
- Test case list auto-refreshes when round status changes

## Bug Fixes

- Fixed environment variable substitution not working in test round execution
- Fixed input field focus loss issue in variable editor
- Removed excessive debug logging for cleaner console output
- Improved visual design and UX for environment dialogs
