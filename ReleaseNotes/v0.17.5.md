# Qaptly v0.17.5

**Release Date**: May 16, 2026

A focused release that makes the AI Assistant noticeably more reliable and adds a second AI engine option.

## New AI Engine Option

- You can now choose between Claude and OpenAI's Codex as your AI Assistant engine — pick whichever account you already have access to.
- Available models are detected automatically from your account, so the dropdown only shows models you can actually use.
- AI settings have been consolidated into a single, clearer "AI Assistant" section.

## A More Reliable AI Assistant

- If the AI Assistant ever exits unexpectedly, Qaptly now resumes the same conversation automatically instead of making you start over.
- When something does go wrong, the error message tells you what happened and how to fix it — no more cryptic failures.
- If your AI CLI isn't signed in yet, you get a clear prompt with the exact command to run instead of a confusing error.
- The model name shown in the assistant header now always matches the model actually being used.

## AI Assistant Input Improvements

- New preference: choose whether **Enter** sends your message or adds a new line. The setting takes effect immediately across all windows.
- The send button now stays in place while a response is streaming.

## Mobile Test Designer

- You can now re-pick the on-screen coordinate when editing an existing tap or press step — no need to delete and re-add the step.

## Quality-of-Life

- Fixed unexpected macOS permission prompts appearing when the app launched. Permissions are now only requested when you actually use a feature that needs them.
