# Qaptly v0.17.0 Release Notes

**Release Date**: March 5, 2026

## Highlights

### Discovery for Mobile Apps
Automatically explore and document your mobile app's screens and navigation. Qaptly uses AI to analyze each screen, identify interactive elements, and build a complete map of your app's structure — no manual effort required.

### Local Scene Search
Search across your recorded scenes locally with fast, privacy-preserving vector search. Works offline with GPU acceleration when available, with automatic CPU fallback.

### iOS GPS Spot Testing Without Companion App
iOS GPS mock now works directly through the device's built-in capabilities — no need to install the Qaptly Auto for iOS companion app for spot testing.

### AI Assistant Model Selection
Choose which Claude model powers your AI Assistant and Discovery sessions. Switch between models for different speed/quality trade-offs.

## Improvements

- **Smarter Discovery**: The discovery engine now handles complex navigation patterns, detects duplicate screens, and automatically skips advertisements
- **Streaming AI Output**: See AI analysis results in real-time as they're generated, with clear progress indicators
- **Better iOS Setup**: Improved setup wizard for iOS device connection with automatic error recovery
- **Simplified AI Assistant Connection**: The AI Assistant now automatically detects your Claude connection — no manual API key entry needed
- **Intervention Controls**: When automatic discovery encounters an obstacle, you get a visual dialog to guide it with screenshots, text input, or tap controls
- **Device List**: All connected devices (Android and iOS) now appear in a single unified list

## Bug Fixes

- Fixed screenshot display for iOS devices in Mobile Test Designer
- Fixed various UI alignment and rendering issues
- Improved stability of AI-powered features
