# Qaptly v0.15.3 Release Notes

**Release Date**: January 22, 2026

## What's New

### Unified Pilot Protocol (UPP) - Now Open for Use

The Unified Pilot Protocol, which allows connecting external hardware devices (like Raspberry Pi, WiFi controllers, or custom IoT devices) to extend your testing capabilities, is now open for use:

- Connect third-party devices via WebSocket protocol
- Secure approval process for new device connections
- Enhanced settings interface for managing connected devices
- Full multilingual support (English, Japanese, Traditional Chinese)

**Note**: This feature is disabled by default for security. Enable it in Settings → Pilots if you want to use external devices.

### Enhanced Log Collection

Better debugging capabilities with comprehensive log collection:

- **Browser Console Logs**: Automatically collect browser console output during test execution (requires browser extension v0.9.0+)
- **Android Device Logs**: Capture Android system logs from connected devices
- All logs are saved to the `execution_logs` directory for easy review

### AI-Powered Element Finder

Finding elements in your mobile app is now smarter:

- AI automatically suggests the best way to locate UI elements
- Improved accuracy for finding buttons, text fields, and other components
- Works seamlessly within the Mobile Test Designer

### Android Testing Improvements

Several enhancements for Android device testing:

- **Faster Device Information**: Optimized how device details are retrieved
- **Better Screen Recording**: Automatically adjusts recording duration based on device capabilities
- **App Management**: Easily install, uninstall, and launch Android apps directly from Qaptly

### Mobile Test Designer Updates

- **Environment Variables**: See actual values of environment variables in your test steps
- **Improved Layout**: More stable dialog heights and better UI consistency
- **Better Screenshot Handling**: Enhanced support for both Android and iOS screenshots


## Bug Fixes

- Fixed dialog height issues that caused unexpected layout changes
- Improved handling of device screenshots across different formats
- Enhanced error handling throughout the application
