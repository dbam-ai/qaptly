# Qaptly v0.15.9 Release Notes

**Release Date**: 2026-01-27

## What's New

### Smarter Device Checking Before Tests
Before starting a test, Qaptly now checks if all required devices are connected. If any device is missing, you'll see a helpful dialog that automatically refreshes until the device is ready.

### Better Mobile Screen Recording
Analysis Sessions can now monitor your mobile device screens more efficiently. Only meaningful screen changes are captured, reducing clutter and storage usage.

### Improved Text Input for All Languages
- Chinese, Japanese, Korean, and other non-English text now works seamlessly
- No more errors when typing special characters
- Automatic handling ensures your text is entered correctly

### More Reliable Android Automation
- Switched to a more compatible default input method
- Fixed issues where scrolling to find elements wasn't working
- Better handling of text verification in tests

### Separated Text Input Settings
You can now control how text is typed separately from other automation settings, giving you more flexibility for different testing scenarios.

## Bug Fixes

- Fixed issues with test templates not loading correctly
- Fixed problems with device list showing incomplete information
- Improved error messages to be more helpful
- Various stability improvements throughout the application
