# Qaptly v0.14.8 Release Notes

**Release Date**: December 19, 2025

## What's New

### AI Agent Integration (MCP Tools)
- Added support for AI agents to control mobile devices through Qaptly
- AI assistants can now perform mobile automation tasks like tapping, swiping, and inputting text
- Enables intelligent test automation powered by AI

### Scene Analysis Improvements
- Completely redesigned scene analysis result viewer with modern card-based layout
- New navigation sidebar for easy access to scenes, steps, and outcomes
- Added "Get Result" button to download completed analysis results
- Better visualization of analysis metadata and scene details

### Screenshot Comparison
- New hover tooltip showing similarity metrics on screenshot cards
- See pixel difference and visual similarity scores at a glance
- Helps understand visual changes between screenshots

## Improvements

- Improved session dialog layout for better usability
- Optimized message logging for better performance
- Various code quality improvements

## Bug Fixes

- Fixed analysis result display issues
- Fixed duplicate upload handling
- Fixed window navigation issues
