# v0.13.6 - Two-Factor Authentication and Security Enhancements

## What's New

### Two-Factor Authentication (2FA) Login Support

Complete implementation of 2FA authentication flow:

- **NEW**: Two-Factor Authentication with intuitive digit input interface
  - Individual digit boxes for easy code entry
  - Auto-focus and keyboard navigation support
  - Paste support for quick code entry
  - Auto-verify when code is complete

- **NEW**: Multi-method 2FA Support
  - Authenticator App (TOTP) - Works with Google Authenticator, Authy, and similar apps
  - Email OTP - Verification code sent to your registered email
  - Recovery Code - 8-digit backup codes for account recovery
  - Automatic method selection when only one option is available
  - Easy switching between methods when multiple options exist

- **IMPROVED**: Login Interface
  - Clean, modern design matching the web portal
  - Updated branding with DBAM logo
  - Automatic credential clearing for enhanced security

- **IMPROVED**: Multi-language Support
  - Full 2FA support in English, Japanese, and Traditional Chinese
  - User-friendly error messages in all supported languages

## Installation

### macOS

1. Download the `.dmg` file from the releases page
2. Open the `.dmg` file
3. Drag Qaptly to your Applications folder
4. Launch Qaptly from Applications

### First-time Setup

If this is your first installation:
1. You may need to allow the app in System Preferences → Security & Privacy
2. Grant necessary permissions when prompted (camera, microphone, accessibility)

### Upgrading from Previous Version

The application will automatically detect the update and preserve your settings.

## 2FA Setup Instructions

If 2FA is enabled on your account:

1. **First Login**: Enter your username and password as usual
2. **2FA Verification**: You'll be prompted to verify your identity
3. **Choose Method**:
   - **Authenticator App**: Enter the 6-digit code from your authenticator app
   - **Email**: Request a code to be sent to your email, then enter it
   - **Recovery Code**: Use one of your 8-digit backup codes if other methods aren't available
4. **Complete**: Your session will be remembered on this device
