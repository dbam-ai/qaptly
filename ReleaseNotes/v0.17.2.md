# Qaptly v0.17.2 Release Notes

**Release Date**: March 16, 2026

## Highlights

### ADB over WiFi One-Click Setup
Connect to Android devices wirelessly with a single click from Pilot Control. No more manual terminal commands for wireless debugging.

### API Test Manager Enhancements
The API Test Manager has been significantly improved with new capabilities and bug fixes for a smoother testing experience.

## New Features

- **Clipboard Image Paste**: Paste images directly from your clipboard when submitting feedback

## Improvements

- **Smarter Stream Detection**: Screen streaming now starts automatically without needing to manually check device capabilities
- **Better Device Step Editor**: Improved layout and visual consistency for device interaction steps
- **Smarter Test Recovery**: The test recovery engine better understands your app's current state when failures occur and plans more effective recovery paths
- **Updated Android Companion**: Bundled Android companion app updated to v1.10.4

## Bug Fixes

- Fixed duplicate device appearing in device list when switching from USB to WiFi connection
- Fixed subscription status not displaying correctly for expired or inactive plans
