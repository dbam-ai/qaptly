# Qaptly v0.14.4

Release Date: 2024-12-04

## What's New

### Mobile Test Settings
- Added new **Mobile Test** settings tab with Android input mode selector
- Supports two input modes for Android devices:
  - **Accessibility** (default): Uses Android Accessibility Service for reliable touch input
  - **ADB**: Uses adb shell input commands for faster execution

### Android Input Mode Support
- Touch, swipe, press, and input commands now support configurable input mode
- Settings are applied dynamically without requiring app restart

### APK Update Notification
- Automatic detection when Qaptly Auto APK needs update on Android devices
- Shows "Update" button in Pilot Control when newer version is available
- Displays toast notification with version comparison

## Bug Fixes

- Fixed CLOSE_APP step displaying incorrect label in Mobile Test Designer
- Corrected Cloud VL pair name mapping for Precise and Fuzzy verification modes
  - Precise mode now uses thinking-enabled verification for better accuracy
  - Fuzzy mode uses standard boolean verification

## Improvements

- Improved auto-updater download progress UI with clearer status indicators
- Added deep merge support for nested user preferences

## Bundled Components

**qaptly_mac_cmd**: v0.26.1-2512041541 (Build: 2024-12-04)

- Add inputMode parameter for Android touch operations (accessibility/adb)
