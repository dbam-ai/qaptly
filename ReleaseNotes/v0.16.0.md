## Getting Started with New Features

### Using Enhanced AI Test Generation

1. Open Mobile Test Designer
2. Click the AI Assistant button (now with Agent SDK support)
3. Describe your test scenario in natural language
4. Review the AI-generated steps in the AI Pool staging area
5. Approve and add to your test case, or modify as needed
6. Optional: Configure third-party AI engines in Settings

### Setting Up SMS Reading

1. Ensure Android device has SMS permission granted
2. In your test case, add a "Get Device Info" step
3. Select "SMS" as the info type
4. Choose how many recent messages to retrieve
5. Use the context variable picker to access SMS content in verification steps

### Controlling Device State

1. Open the Devices tab
2. Select your Android device
3. Use the WiFi, Mobile Data, or Airplane Mode controls
4. Or add device control steps directly in your test case
