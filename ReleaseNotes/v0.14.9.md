# Qaptly v0.14.9 - Unified Test Editor

**Release Date**: December 20, 2025

## What's New

### Unified Editor for Web and Mobile Steps

No more switching between different editors! The Mobile Test Designer now lets you edit both web and mobile automation steps in one place. Create your complete test scenarios with a seamless editing experience.

**What's Improved**:
- **Single Editor Interface**: Edit web steps and mobile steps together without switching tools
- **Browser Setup Wizard**: New visual guide to help you set up browser automation with screenshots and troubleshooting tips

### Enhanced Image Comparison

Improved accuracy and reliability when comparing screenshots to detect visual changes in your applications. The updated image analysis provides more consistent results across different testing scenarios.

### Streamlined Workflow

When you open the Mobile Test Designer, Qaptly automatically switches to the appropriate mode so you can start creating tests right away without extra clicks.

### UI Improvements

**Scene Analysis Results**: Redesigned interface with better visual organization for clearer presentation of analysis results.

**Browser Connection Status**: Enhanced visual indicators and status displays for browser automation connectivity.
