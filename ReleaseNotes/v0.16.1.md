## What's New

### Android Screen Capture Improvements
- Enhanced reliability of Android screen capture with automatic fallback when screen recording is unavailable
- Clear visual feedback when fallback mode is active
- Improved error handling with helpful guidance messages

### Smart Element Detection
- AI-powered element locator with improved accuracy
- Better positioning and scaling for elements on different screen sizes
- Streamlined confirmation process for detected elements

### Extract Information from Screen
- New ability to extract custom data fields directly from your app screens
- Flexible field configuration to capture the information you need

### Device Management Enhancements
- Automatic detection when newer Android automation package is available
- Clearer "Upgrade" action with improved visual feedback
- Smoother loading states with spinner indicators
- Status updates reflect real-time connection state

### Android Automation Package v1.8.7

#### GPS Location Features
- More reliable GPS mock service for location-based testing scenarios
- Optimized performance with reduced battery impact

#### Improvements
- Better service reliability for background automation tasks

- Consistent input field sizes across all step editors
