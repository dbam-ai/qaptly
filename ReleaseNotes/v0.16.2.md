## What's New

### Simplified Android Setup
- **Automatic Screen Mirroring Support**: No need to manually install additional tools for Android screen mirroring
- **One-Click Installation**: All required Android tools are now installed together in a single step
- **Easier Setup Process**: Streamlined installation workflow saves time and reduces setup complexity

### GPS Route Planning for Android Testing
- **Plan Custom Routes**: Create test routes between any two points on the map
- **Multiple Travel Modes**: Choose between walking, biking, driving, or set your own custom speed
- **Visual Route Display**: See your planned route drawn on the map with clear start and end markers
- **Adjustable Playback Speed**: Control how fast the simulated movement plays (0.5x to 5x speed)
- **Real-time Tracking**: Follow your current position on the map during playback
- **Progress Information**: View distance covered, elapsed time, and remaining time
- **Flexible Controls**: Pause, resume, or restart your route at any time

### Enhanced GPS Mock Stability
- **More Reliable Location Simulation**: Improved GPS mocking prevents your device from jumping back to real location
- **Smoother Playback**: Continuous location updates ensure smooth trajectory replay without gaps
- **Better App Compatibility**: Works more reliably with apps that use multiple location sources

## Installation

Download the latest version from [GitHub Releases](https://github.com/dbam-ai/qaptly/releases).

For macOS users:
1. Download `Qaptly-0.16.2-arm64.dmg`
2. Open the DMG file
3. Drag Qaptly to your Applications folder
4. Launch Qaptly
