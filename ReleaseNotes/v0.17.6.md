# Qaptly v0.17.6

## New AI assistant: GitHub Copilot

Pick GitHub Copilot as the AI assistant in **Settings → AI Assistant**, alongside Claude Code and Codex. Signing in via `copilot login` in Terminal is enough — the app picks up your Copilot subscription and shows the models available on your account (Claude Sonnet 4.6, Claude Haiku 4.5, GPT-5.4, GPT-5.3-Codex, and more, depending on your plan).

The Mobile Test Designer behaves the same regardless of which AI you choose: same chat experience, same tool capabilities, same streaming, same Stop button.

## Friendlier model picker

When the AI assistant cannot reach the chosen provider (not signed in, network problem, …), the model dropdown now tells you what happened and offers a Retry button with a clear hint — for example, "open Terminal and run `copilot login`, then retry". No more silent loading or blank lists.
