# v0.13.7 - Google Sign-In Support

**Release Date:** 2025-01-24

## What's New

### Google Sign-In Support

Added Google OAuth 2.0 authentication for desktop application, providing users with a convenient alternative login method.

**Key Features:**
- One-click sign-in with Google account
- Secure OAuth 2.0 with PKCE flow
- System browser integration for authentication
- Automatic account linking for existing users

**User Experience:**
- Click "Continue with Google" button on login screen
- Authenticate in your default web browser
- Automatically return to the application
- Seamless integration with existing account system

**Security:**
- Industry-standard OAuth 2.0 protocol
- PKCE (Proof Key for Code Exchange) for enhanced security
- No password storage on device
- Secure token management

**Note:** Desktop users signing in with Google for the first time must complete web registration before using the desktop application.
