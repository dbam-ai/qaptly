# v0.12.9 - Element Locator + Critical Bug Fix

**Release Date**: 2025-11-10

## What's New

### Element Locator Support (KAN-263)
- **NEW**: Find elements by properties (text, resource-id, class, content-desc)
- 5 locator strategies for flexible element finding
- Scroll options: scroll to top first, configurable max attempts
- Smart fallback to coordinates if element not found
- Auto-fill description from locator value

## Critical Bug Fixes

### Progress Callback Timeout Reset (KAN-263)
- **FIXED**: Timeout reset on progress updates now works correctly
- Supports long scroll operations (15+ seconds)
- Dynamic 10-second timeout window on each progress message

**qaptly_mac_cmd**: Latest version with find_element progress update support
