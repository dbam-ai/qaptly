# v0.13.5 - Macro Manager and UI Improvements

**Release Date**: 2025-11-20

## What's New

### Macro Manager
- **NEW**: Complete macro management interface with create, list, delete, and clone operations
- Multi-platform support (Web, iOS, Android, Mobile, API) with smart selection logic
- Steps editor with reordering capabilities
- Parameters editor with type selection
- Search and filtering by platform
- Pagination support

### UI Improvements
- **NEW**: Collapsible fields for better editor experience
- Applied to Description and Preconditions fields in test case editors
- Reduces visual clutter and improves focus
- Smooth animations and persistent state

### Code Organization
- Centralized test constants for platforms and step types
- Improved maintainability and consistency across the application

## Bug Fixes
- Fixed UI layout issues in macro creation dialog
- Improved form validation and error handling
- Optimized spacing and visual clarity in editors

## 📦 Bundled Components

**qaptly_mac_cmd**: v0.25.0-2511190250 (Build: 2025-11-19 02:50)
- Renamed iOS command for clarity: `ios_app_list` → `ios_running_apps`
- Updated documentation to clarify command behavior
- Command returns only currently running apps (not all installed apps)
