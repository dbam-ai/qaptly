# v0.15.5 - Enhanced Reliability and User Experience

Release Date: 2026-01-25

## What's New

### Reliable Upload System
- **NEW**: Automatic retry and recovery for file uploads
  - No more lost uploads when network is unstable
  - Automatic retry with smart backoff when uploads fail
  - Real-time upload progress indicator
  - Queue management for handling multiple uploads smoothly
  - Works across screenshots and test execution data

### Smarter Test Case Management
- **NEW**: Automatic platform detection and management
  - Test case platforms now update automatically based on your test steps
  - No need to manually set platforms anymore
  - Platform compatibility warnings to help avoid mistakes
  - Improved organization with better folder and test case structure

### Cleaner User Experience
- **IMPROVED**: Streamlined notifications
  - Removed excessive notification popups for a cleaner interface
  - Only important messages are shown now
  - Less distraction, more focus on your testing work

### Subscription Information
- **NEW**: Clear subscription and credits display
  - See your available credits at a glance
  - Better visibility of your plan features
  - Improved performance when checking subscription status

### Interface Improvements
- **IMPROVED**: Simplified menu terminology
  - Cleaner, more intuitive menu labels
  - Consistent naming across the application
  - Available in English, Japanese, and Traditional Chinese

### Reliability Enhancements
- **FIXED**: Better error handling throughout the application
  - Improved recovery when switching between workspaces
  - More reliable handling of network issues
  - Smoother operation in various edge cases
