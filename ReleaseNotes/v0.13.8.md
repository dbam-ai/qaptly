# v0.13.8 - Test Specification & Collection Enhancements

**Release Date**: 2025-11-26

## What's New

### Enhanced Scene Analysis Dialog

- **NEW**: Multi-test case format support with tabbed layout for better organization
- **NEW**: Terms calibration functionality - edit and replace terms across all test cases
- **NEW**: Visual feedback for term changes with arrow notation (original → edited)
- **NEW**: Related test cases display with occurrence highlighting
- **IMPROVED**: Larger dialog size (85% width, 85vh height) for better readability
- **IMPROVED**: BDD scenarios with visual grouping and styled sections

### Mobile Specification Collection

- **NEW**: Unified data collection architecture supporting multiple sources
- **NEW**: Mobile device specification collection with voice recording and screenshots
  - Real-time duration tracking
  - Automatic screenshot capture at configurable intervals
  - Audio chunk tracking for voice recordings
- **NEW**: Collection controls integrated into Mobile Test Designer
- **IMPROVED**: Better session and subsession management for organized data

### Enhanced Test Case Display

- **NEW**: Multi-test case format with expandable/collapsible cards
- **NEW**: Color-coded BDD step types (Given/When/Then/And) for quick identification
- **NEW**: Action type tags with semantic colors
- **NEW**: Copy individual test cases to clipboard
- **IMPROVED**: Numbered test steps for easy reference
- **IMPROVED**: Better structured layout and consistent styling

### Seamless App Updates

- **NEW**: ZIP-based hot update system for faster, more reliable updates
- **NEW**: Automatic version checking and update notifications
- **IMPROVED**: Update without full reinstall - saves time and preserves settings

## Bug Fixes

### Login & Authentication

- **FIX**: Two-factor authentication dialog now displays correctly
- **FIX**: TOTP authentication method properly recognized
- **IMPROVED**: Error messages now display inline instead of modal dialogs
- **IMPROVED**: Input field sizing to prevent text compression
- **IMPROVED**: Sign In button disabled when credentials are incomplete

## Highlights

This release focuses on **improving test specification workflows** with:

1. **Better Multi-Test Case Support**: Handle complex test scenarios with multiple test cases in a single specification
2. **Mobile Collection**: Collect test specifications directly from mobile devices with synchronized voice and screenshots
3. **Improved Visualization**: Color-coded BDD steps and better organized test case display
4. **Seamless Updates**: Faster update process that doesn't require full reinstallation

## System Requirements

- **macOS**: 11.0 (Big Sur) or later
- **Architecture**: Apple Silicon (M1/M2/M3) or Intel x64
- **Disk Space**: ~200 MB

## Upgrade Notes

This release is fully backward compatible with v0.13.7. All existing test cases, specifications, and settings will be preserved.
