# v0.14.6 - Enhanced Android Support and Mobile Test Designer Improvements

**Release Date**: 2025-12-14

## What's New

### Enhanced Android Text Input
- **NEW**: Full Unicode text input support for Android devices
- Supports Chinese, Japanese, Korean, emoji, and special characters
- Improved text input reliability through Android IME (Input Method Editor)
- Better automation experience for international languages

### Mobile Test Designer UX Improvements
- **NEW**: Automatic UI element analysis when selecting coordinates

  - Faster workflow with reduced manual steps
  - No duplicate analysis when switching between actions
- **NEW**: Visual error indicators for environment variables
  - Clear warnings when required variables are missing
  - Helps prevent runtime errors during test execution
- **NEW**: Enhanced app close action editor
  - Environment variable selector for dynamic package names
  - "Same as Launch" quick option
  - Consistent experience across all step editors

### Performance & Stability

## Installation

### macOS (Apple Silicon)
1. Download `Qaptly-0.14.6-arm64.dmg`
2. Open the DMG and drag Qaptly to your Applications folder
3. On first launch, right-click the app and select "Open" to bypass Gatekeeper

### Auto-update
Existing users will receive an automatic update notification. The update downloads in the background and installs on next app launch.

## System Requirements
- macOS 13.0 (Ventura) or later
- Apple Silicon (M1/M2/M3) Mac
