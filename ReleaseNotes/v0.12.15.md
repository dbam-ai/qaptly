# v0.12.15 - AI Precision Mode & Training Mode

**Release Date**: 2025-01-12

## What's New

### AI Prompt Precision Mode (KAN-297)
- **NEW**: Precision Mode selector for AI-powered test verification
- Two modes: Fuzzy (flexible semantic matching) and Precise (exact matching)
- Smart mode switching based on test requirements

### Enhanced Execution Info (KAN-294)
- **IMPROVED**: Execution info tracking with detailed metadata
- New fields: `duration` (ms) and `deviceInfo` (platform, name, OS, resolution)

### Training Mode Access Control (KAN-293)
- **NEW**: Training Mode capability reporting and access control
- Frontend checks server capability before enabling features
- Graceful degradation when server doesn't support Training Mode
