# Qaptly v0.16.3

**Release Date**: 2026-02-24

## What's New

### Enhanced GPS Location Control in Mobile Test Designer
- GPS mock and stop actions can now be added directly as test steps
- Paste coordinates from clipboard for quick latitude/longitude input
- Validation ensures GPS mock parameters are complete before execution
- Improved companion app stability on Android 14+

### Enhanced iOS GPS Mock
- Expanded GPS mock controls in the Pilot Control panel for iOS devices
- Streamlined start, stop, and status check workflow for iOS GPS mock

### Android Device Screen Streaming
- Live screen streaming from Android devices in the Mobile Test Designer
- Automatic detection of streaming capability when a device is selected
- Reliable fallback behavior when streaming is not available

### Spec Discovery (Preview)
- New Spec Discovery window for AI-powered analysis of application screens
- Analyze pages, evaluate forms, plan actions, compare screens, and categorize features

## Bug Fixes

- Fixed GPS mock version check that was incorrectly comparing against the desktop app version instead of the device companion app version
- Fixed a crash on Android 14+ devices when starting GPS mock (companion app update)
- Fixed device streaming detection that could incorrectly show streaming controls
