# Qaptly v0.17.4

## What's New

### Mobile Test Designer Improvements
- **AI Assistant more reliable**: The AI assistant in Mobile Test Designer is significantly more stable and responsive, with better handling of complex test sequences and improved error recovery.
- **Fixed save issue after window switching**: Test cases now save correctly even after switching windows or switching focus to another app during editing.

### Android Automation
- **Detect invalid input method**: Qaptly now detects when the Android device's input method is not compatible and shows a clear warning, preventing silent failures during text input automation.
- **Updated Android agent**: Android automation binary updated to v1.12.0.

### General Fixes
- **Two-Factor Authentication**: Fixed a rare issue where submitting the 2FA code too quickly could cause a double-submit.
- **Step Editor**: Cleaned up stale parameters when switching between step types, preventing unexpected behavior.
