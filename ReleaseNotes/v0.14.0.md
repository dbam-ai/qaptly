# v0.14.0 - MCP Integration and Spec V2 Workflow

**Release Date**: 2025-11-29

## What's New

### 🚀 MCP (Model Context Protocol) Integration

**NEW**: Claude Desktop integration enabling AI-powered automation workflows.

- **MCP Operation Mode**: Secure control interface for Claude Desktop integration
- **Real-time Task Tracking**: Visual feedback for MCP operations with task queue display
- **User Confirmation**: All MCP requests require explicit approval for security
- **Native Bridge**: Lightweight macOS bridge connecting Claude Desktop to Qaptly
- **Unified Device Management**: Organized device list for browsers, iOS, and Android devices

**How it works**:
1. Configure Claude Desktop to connect to Qaptly via MCP settings
2. Claude can now control Qaptly for automation tasks
3. Every operation requires your confirmation for security
4. View real-time task progress in the MCP overlay

### 🔒 Security Enhancements

**NEW**: Comprehensive security features for safe MCP operations.

- **Audit Logging**: All MCP operations logged with daily rotation
- **Auto-timeout**: Configurable timeout to prevent runaway tasks (default: 5 minutes)
- **Socket Security**: Unix Socket permissions restricted to current user only
- **Busy Protection**: Prevents concurrent MCP operations

### 📋 Spec V2 Workflow

**NEW**: Improved specification collection with two-stage workflow.

- **Two-Stage Process**:
  1. **Scene Analysis**: Record and analyze test scenarios with voice + screenshot
  2. **Spec Extraction**: Automatically extract structured specifications from analyzed scenes
- **AI-Powered Analysis**: Uses GPT-4 Vision for scene understanding
- **Structured Output**: Organized specifications ready for test case creation

### 🌐 Language & Internationalization

**Improved**: Better language management across the application.

- **Centralized Control**: Set language preference in Settings > General
- **Instant Updates**: Language changes apply immediately to all windows
- **Persistent Preference**: Your language choice is remembered across sessions
- **Consistent Experience**: Synchronized language across all UI components

### 🐛 Bug Fixes

- **MCP Reconnection**: Improved connection recovery when app restarts
- **Connection Handling**: Better error messages when Qaptly is unavailable
- **Training Mode**: Fixed IPC communication issue in training mode toggle
- **Device List**: Resolved timing issues in mobile device list loading

## Installation

### macOS ARM64 (Apple Silicon)

**First-time Installation**:
1. Download `Qaptly-0.14.0-arm64.dmg`
2. Open the DMG and drag Qaptly to Applications
3. Launch Qaptly from Applications
4. Grant necessary permissions when prompted

**Automatic Update** (for existing users):
- Qaptly will automatically download and install updates
- You'll be notified when an update is ready

### Requirements
- macOS 13.0 or later
- Apple Silicon (M1, M2, M3) processor
- ~150 MB disk space

### Post-Installation

1. **Grant Permissions**: Allow Accessibility and Screen Recording access when prompted
2. **Set Language**: Go to Settings > General to set your preferred language
3. **MCP Setup** (optional): If using Claude Desktop, configure MCP settings in Settings > MCP Settings

## MCP Integration Setup (Optional)

To enable Claude Desktop integration:

1. **Configure Claude Desktop**:
   - Add Qaptly MCP server to Claude Desktop settings
   - Restart Claude Desktop

2. **Enable MCP Mode in Qaptly**:
   - Open Settings > MCP Settings
   - Enable MCP Operation Mode
   - Configure timeout duration (default: 5 minutes)

3. **Start Using**:
   - Claude can now control Qaptly for automation tasks
   - All operations require your confirmation
   - View task progress in the MCP overlay

For detailed setup instructions, see the MCP integration guide in Settings > MCP Settings.
