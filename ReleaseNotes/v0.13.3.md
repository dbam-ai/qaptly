# v0.13.3 - iOS Integration Improvements

**Release Date**: 2025-11-19

## What's New

### iOS Running Apps Management
- **Improved iOS app management interface** with better organization and clarity
- Renamed app list command to accurately reflect that it shows running apps only
- Reorganized iOS control buttons into logical groups for better usability:
  - Basic operations (Screenshot, Tap Test, Text Input)
  - App Management (Running Apps, Launch App)
  - Navigation (Home)
  - Gestures (Swipe, Long Press)

### UI Improvements
- Fixed iOS Running Apps dialog to correctly display bundle IDs without duplication
- Improved app status display with accurate running/stopped indicators
- Added "Launch App" functionality for starting iOS apps by bundle ID
- Enhanced "Terminate App" button with visual distinction (red color)

- Corrected app count display for iOS running apps
- Improved data structure handling for iOS app information
