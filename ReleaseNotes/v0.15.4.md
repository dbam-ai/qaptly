# v0.15.4 - Round Template Improvements and Performance Optimizations

Release Date: 2026-01-23

## What's New

### Round Template Management
- **NEW**: View template details with easy navigation back to the list
- **NEW**: Drag and drop to reorder test cases in your templates
- **NEW**: Resizable panels - adjust the layout between available and selected test cases to your preference
- **IMPROVED**: Click template names directly to view details
- **IMPROVED**: Cleaner, more consistent interface matching the test round pages

### Performance Improvements
- **FASTER**: Test execution now runs more efficiently with pre-processed test data
- **RELIABLE**: More predictable test execution results

### Pool and Set Manager
- **IMPROVED**: Better error handling when managing test pools and sets
- **IMPROVED**: Clearer feedback during operations

## Bug Fixes
- Fixed issue where folder tree state was lost when creating new folders or test cases
- Fixed Android text input compatibility on some devices
