# v0.15.2 - User Feedback and GPS Testing Features

**Release Date**: January 19, 2026

## What's New

### User Feedback

- **NEW**: Send feedback directly from the application
  - Attach screenshots to illustrate issues
  - Categorize your feedback (bug reports, feature requests, improvements)
  - Get confirmation when your feedback is received

### GPS Testing (Android)

- **NEW**: Mock GPS location for testing location-based features
  - Set your device to any GPS coordinates instantly
  - Test location-based app behaviors without physically moving
- **NEW**: GPS trajectory replay
  - Play back recorded GPS paths for route-testing scenarios
  - Control playback speed (e.g., 2x for faster testing)
  - Loop trajectories for continuous testing
- **NEW**: GPS setup guidance during device onboarding
  - Easy one-click setup for mock location permissions

## Improvements

- Better event tracking during device setup
- Fixed version display in settings
- Improved Windows platform compatibility
