# Qaptly v0.17.7

## Knowledge Layer for the AI assistant

Your AI assistant in the Mobile Test Designer now learns and remembers per app. Once a Case is linked to its app, every fact you seed, every correction you make, and every recovery the assistant works out becomes reusable knowledge for that app.

- A new strip above the chat input shows what the assistant currently knows for this app, and lights up when something new is learned.
- Click **＋** to teach the assistant a fact directly (UI behaviour, business rule, naming convention…). The next time you ask it to design or recover a step, it pulls those facts in automatically.
- Click the 💭 icon to inspect every learned fact and decision rule, lock the ones you trust, or reject anything that turned out wrong.
- Patterns the assistant figures out during failure recovery are saved as decision rules and re-applied automatically the next time the same situation appears. Repeated successes promote a rule from "suggestion" to "auto-apply".

## Link a Case to its app

Each Case can now be bound to the app it tests with a one-click target picker in the Mobile Test Designer. This is what gives the Knowledge Layer its per-app scope — your learnings stay with the app they belong to and won't leak across Cases targeting different apps.

## Smarter verification handling

The assistant treats verification intent as a first-class outcome:

- When you ask the assistant to verify or check something, it always produces a real verification step instead of quietly substituting a wait + screenshot.
- The assistant will never delete a verification step just to make a Case "pass". When something goes wrong, it surfaces the failure and asks you instead.
- A Case is only marked done once every verification you asked for is actually covered.

## API Tester: Swagger 2.0 import

Importing an OpenAPI spec now also accepts Swagger 2.0 files. Many official APIs (TWSE and other government / financial endpoints in Taiwan and Japan) are still published as Swagger 2.0 — drop them in and it just works, no manual conversion.

## API Tester: cleaner, theme-aware look

The API Tester window has been visually refreshed to match the rest of the app. Cards are lighter, spacing is consistent, and colours follow the application theme instead of being hardcoded — so the window looks at home next to the test case manager and follows your theme correctly.

## Reliability fixes

- The Mobile Test Designer's AI tools no longer get stuck after you press **Stop**. The next message picks up cleanly without needing a window reload.
- Navigation items now refresh correctly when you switch between tenants, so plan-specific features show up immediately instead of waiting for a reload.
