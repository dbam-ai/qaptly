# v0.13.1 - Complete Internationalization & Bug Fixes

**Release Date**: 2025-01-14

## What's New

### Complete Internationalization Support

- COMPLETE multi-language support across the entire application
- Mobile Test Designer: All step editors now support EN, JA, ZH-TW
- API Tester: Fully internationalized menu items and labels
- Manual Test Execution: Complete i18n implementation
- Automated i18n validation tool to ensure translation consistency

### Bundled Components Widget

- NEW "Qaptly Components" widget in PilotControl window
- Displays version information for bundled components
- Shows qaptly_mac_cmd, qaptly-auto-android, and WebDriverAgent versions
- Improved layout and better visual organization

## Bug Fixes

### Security Improvements

- Removed authentication token and tenantId from logs
- Enhanced security for production deployments

### WebSocket Stability

- Fixed WebSocket toggle state synchronization
- Removed redundant cleanup calls
- Improved connection reliability

### UI Improvements

- Fixed WDASetupWizard prop type warning
- Simplified PilotControl layout
- Added missing i18n keys across all components
